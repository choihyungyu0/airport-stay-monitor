[재현 3단계]
① 데이터랩 외래객 지역별 방한현황에서 대상 시도·시군구의 국가별 방문·카드소비(월별)를 내려받는다
② 관광지식정보시스템 입국관광통계에서 입국항 × 국가 × 월별 입국자를 내려받는다
③ compute_indicators.py 실행 → 지표① 입국 1인당 권역 카드소비, 지표② 방문 배율, 검정·요인분해 출력

[산식]
지표① = 권역 국적별 외국인 카드소비(반기 합) ÷ 해당 공항 국적별 입국자(반기 합)
지표② = 권역 국적별 월 방문자 ÷ 해당 공항 국적별 월 입국자 (월평균, 방문자수 합산 금지)
V2 채택 = 수준·전월차분 상관 모두 지역공항 > 인천, 차분 상관 ≥ 0.5

[데이터 사용 원칙]
- 방문자수: 일자별 순방문자 기준 연인원 추정치. 시간·공간 합산 금지(공사 가이드라인), 월평균 비율만 사용
- 카드: 외국 발행 신용카드 결제분. 추세·비교용. 2026.8 재소급 이후 추출분
