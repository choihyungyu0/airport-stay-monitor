# 공항 체류전환 모니터

2026 한국관광 데이터랩 활용 경진대회 · 응모작 시제품(웹)
**배포** → https://airport-stay-monitor.vercel.app

지방공항으로 들어온 외래객이 **그 권역에 며칠 머물고 얼마를 쓰는지**, 한국관광 데이터랩 공개 데이터로 매달 국적별·시군구별로 산출해 보여 주는 웹입니다. 청주·대구·김해 공항을 같은 산식으로 비교하고 제주는 기준선으로 둡니다.

> 청주공항 대만 입국자는 2026 상반기에 **두 배(+105%)** 늘었지만, 입국 1인당 충북 카드소비는 **36,790원**으로 제자리입니다.
> 김해공항 대만 입국자는 부산에서 **440,089원**을 씁니다. 공항 소재지 청원구는 방문이 가장 많은데 방문 1회당 소비는 **1,975원**으로 가장 적습니다.

- 1차 사용자: 충북도·청주시 관광 담당, 청주공항 활성화 협의체, 충북문화재단(권역형 DMO), 심사위원

## 화면 — 첫 화면은 위성지도, 담당자가 매달 쓰는 네 탭

| 탭 | 주소 | 하는 일 |
|---|---|---|
| 지도 | `#map` | 전면 위성지도(V-World 위성 + 하이브리드 라벨). 공항 4곳 원(크기 = ② 체류 인·일, 채움 = ① 1인당 카드소비, 청주 노랑·제주 점선 참고값), 출발 안내판 패널, 월별 재생, 공항 반경 5·10km 숙박 공급. 「청주 권역 보기」 → 충북 14개 시군구 단계구분도(위성 위 투명도 0.55)·시군구 표·대만 타깃 콘텐츠 6곳. 「숙박·음식 건물」을 켜면 줌 14부터 숙박·음식·소매 업소가 든 건물 3,634동(청주 4구·충주·제천 시내·단양읍), 건물을 누르면 주용도·층수·사용승인연도·업소 목록·시군구 평균. 아래로 반기 핵심 지표·월별 추이·1인당 소비 변화 요인 |
| 효과 계산 | `#effect` | 대상 입국자·체류 증가일·상한 공항·사업비를 넣으면 추가 카드소비와 「추가 카드소비 ÷ 사업비(단순 배수)」, 예산 요구서용 산출 근거 |
| 보고 문안 | `#report` | 월간 동향 · 반기 분석 · 사업 효과 근거를 □○-※ 개조식으로 작성. **한글 파일(.hwpx)** 저장, 복사, .txt 저장 |
| 자료·검증 | `#data` | 검증 6종, 데이터 점검 9항목, 산식, 출처, 한계, 연동 검정 전체 표 |

국적(대만·일본)은 어느 탭에서든 상단에서 바꿉니다. 문안과 요약 문장은 `src/lib/report.ts`·`story.ts`가 산출 JSON에서 만들므로 숫자가 화면 값과 어긋나지 않습니다. 예전 주소(`#overview` `#sgg` `#summary` `#trend`)는 `#map`으로, `#method`는 `#data`로 바뀝니다.

### 지도에서 지키는 것(보안·약관)

- 배경은 **V-World 타일만**(위성·하이브리드·midnight). 구글·네이버·카카오 타일 없음, 하단에 「국토교통부 브이월드」 출처
- 최대 줌 **12**(시군구 규모). 「숙박·음식 건물」을 켠 때만 **17**. 공항은 점 하나(소수 둘째 자리 좌표)이고 시설명·활주로 라벨·3D 없음. 청주·대구·김해는 공군과 활주로를 같이 쓰는 공항(`military_shared`)
- **공항 보호구역**: 청주·대구·김해 중심 3km는 줌 13 이상이면 불투명 마스크(「공항 보호구역 · 확대 표시 안 함」)로 덮고, 그 안의 건물·업소 위치는 산출물에 넣지 않습니다(개수만, `tests/test_buildings.py`가 확인)
- 실행 중 외부 호출은 V-World 타일뿐(글꼴 파일 제외). 콘텐츠 지점 좌표·건물 윤곽은 빌드 때 한 번 V-World에서 받아 정적 파일로 고정(`scripts/geocode_pins.py`, `scripts/build_buildings.py`)
- 타일이 실패하면 위성 → 지도(midnight) → 배경 없음 순으로 물러나며 안내

- 기능명세: `공항_체류전환_모니터_기능명세서.xlsx` v1.0 (기능ID·UI_id·규칙ID를 코드 주석과 `data-ui` 속성에 그대로 씁니다)

### V-World 배경지도(UI-05, 선택)

`.env.local`에 국토교통부 브이월드 인증키(이 서비스 전용 개발키, 서비스 URL `airport-stay-monitor.vercel.app`, 2027-03-29 만료 — 만료 전 브이월드 마이포털에서 연장)를 넣으면 지도 배경에 「지도」(WMTS `white`, 어두운 화면에서는 `midnight`)와 「위성」(`Satellite`)을 쓸 수 있습니다. Vercel에서는 프로젝트 환경변수 `VITE_VWORLD_KEY`로 넣고, 브이월드에 배포 도메인을 서비스 URL로 등록합니다.

```
VITE_VWORLD_KEY=발급받은-키
```

- 키가 없거나 타일을 못 받으면 「배경 없음」으로 되돌리고 안내합니다(ST-08). 기본값도 「배경 없음」입니다(단계구분도 가독성).
- **V-World 타일만** 요청합니다. 구글·네이버·카카오 타일은 쓰지 않습니다. 최대 줌 12(건물 레이어를 켠 때만 17, 공항 3km는 줌 13부터 마스크), 공항 시설 확대·주석 표시 없음(BR-U3 — 청주·대구·김해는 군 공용 공항).
- 키는 코드에 적지 않습니다.

## 월 1회 갱신 절차 (OPS-01)

1. 데이터랩 **공식 화면·다운로드**로 받은 CSV를 `data/raw/`에 교체합니다(자동 수집 코드 금지, BR-C1). 파일명이 바뀌면 `data/config/sources.json`을 고칩니다.
2. `data/config/sources.json`의 `datalab_extract`(화면 표기)와 `card_extracted_on`(카드 추출일)을 고칩니다. 추출일이 2026-08-11 재소급 이전이면 경고가 뜹니다(BR-D3).
3. 두 명령으로 끝납니다.

```bash
npm run build:data     # 산출 + 검증 리포트 출력(FAIL이면 종료 코드 1)
git commit -am "데이터 2026.MM 갱신" && git push   # CI 통과 후 Vercel 배포
```

- 비교 반기를 옮길 때는 `data/config/settings.json`의 `halves`·`sgg.period`를 바꾸고 `tests/expected.json`을 새 기대값으로 교체합니다.
- 검증 관문: `npm run build`가 먼저 `scripts/check_report.mjs`를 돌려, 산출 JSON이 없거나 리포트에 FAIL이 있으면 **빌드(=배포)를 멈춥니다**. 시도-시군구 불일치 같은 경고는 빌드를 멈추지 않고 화면에 배지로 보입니다(DAT-06, ST-09).
- CI(`.github/workflows/ci.yml`)는 원천에서 다시 산출해 커밋된 JSON과 같은지(`npm run check:data`), 테스트, 빌드를 확인합니다.

## 건물 레이어 다시 만들기(지시서 8장)

사각119(`scripts/fetch_buildings.py`)와 같은 방식으로, 빌드 때 브이월드 WFS(`lt_c_bldginfo`, 국토교통부 GIS건물통합정보)에서 건물 윤곽·주용도·층수·사용승인일을 받아 소상공인시장진흥공단 상가(상권)정보와 잇습니다. 실행 중에는 `public/data/buildings/*.json`만 읽습니다.

1. `소상공인시장진흥공단_상가(상권)정보_20260630.zip`에서 충북 CSV를 `data/external/상가정보_충북_202606.csv`로 풉니다(52MB, 커밋하지 않음 — `.gitignore`).
2. `python scripts/build_buildings.py` — `.env.local`의 `VITE_VWORLD_KEY`로 업소가 모인 약 1km 칸 384개를 묻고(요청 약 700건, 1,000건이 차면 4등분), 응답은 `data/external/wfs_cache/`에 남깁니다. 다시 만들 때는 `--offline`(캐시만).
3. 결과: 구역별 `public/data/buildings/{시군구코드}.json`(좌표 소수 5자리) + `index.json`(수집일·출처·보호구역 안 업소 수·잇기 통계).

| 항목 | 규칙(`data/config/buildings.json`) |
|---|---|
| 범위 | 청주 4구 전체 · 충주·제천 동 지역 · 단양읍. 청주공항 3km 제외 |
| 업소 | 상권업종대분류 숙박·음식·소매 37,562곳(보호구역 108곳은 개수만) |
| 잇기 | 업소 좌표가 든 건물 31,762 → 같은 지번(50m 안) 1,441 → 15m 안 가장 가까운 건물 1,154 · 못 이음 3,205(8.5%, 대부분 업소가 드문 칸) |
| 남기는 건물 | 주용도 숙박시설(건축물대장 코드 15000) 또는 업소 3곳 이상 → 3,634동 |
| 색 | 숙박시설 노랑 · 근린생활·판매시설 청록 · 그 밖 회색 테두리 |

건물 패널의 외국인 값(월평균 방문·방문 1회당 카드소비)은 소속 시군구 값을 그대로 가져와 「시군구 평균」으로 표시합니다. 건물별 외국인 소비·방문 값은 없어서 만들지 않습니다.

## 구조

```
data/raw/        원천 CSV·경계(사용자가 교체). 받은 바이트 그대로 보관
data/config/     airports.json(공항-권역 쌍) · region_map.json(지역·국가명·코드 대응) · gu_cities.json(구 설치 시 보정)
                 settings.json(임계값·비교 반기) · sources.json(파일·추출일) · reference_values.json(공사 발표·원자료 결과값)
data/external/   상가정보 CSV · 브이월드 WFS 캐시(커밋하지 않음)
scripts/         indicators.py(산식, 표준 라이브러리) · build_data.py(적재·경계 변환·리포트·JSON) · check_report.mjs(배포 관문)
                 build_buildings.py(건물 레이어) · geocode_pins.py(콘텐츠 지점 좌표)
tests/           test_indicators.py · test_buildings.py · expected.json(기대값)
public/data/     indicators.json · sgg.json · boundary_43.geojson(WGS84) · meta.json(기준 시점·검증 리포트) · buildings/(구역별 건물)
src/             React 화면(Vite + TypeScript, 지도 react-leaflet, 차트 SVG 직접 구현)
reference/       시제품 airport_monitor.html · compute_indicators.py(정답 구현) · 재현 안내
```

공항을 늘리려면 `airports.json`에 한 줄을 넣고 `npm run build:data` 하면 카드·차트에 자동으로 붙습니다(UI-12). 해당 권역 데이터랩 자료가 없으면 「자료 없음」, V2 검정을 통과하기 전에는 「참고값」으로만 보입니다.
