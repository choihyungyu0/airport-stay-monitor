# 공항 체류전환 모니터

2026 한국관광 데이터랩 활용 경진대회 · 응모작 시제품(웹)

지방공항으로 들어온 외래객이 **그 권역에 며칠 머물고 얼마를 쓰는지**, 한국관광 데이터랩 공개 데이터로 매달 국적별·시군구별로 산출해 보여 주는 웹입니다. 청주·대구·김해 공항을 같은 산식으로 비교하고 제주는 기준선으로 둡니다.

> 청주공항 대만 입국자는 2026 상반기에 **두 배(+105%)** 늘었지만, 입국 1인당 충북 카드소비는 **36,790원**으로 제자리입니다.
> 김해공항 대만 입국자는 부산에서 **440,089원**을 씁니다. 공항 소재지 청원구는 방문이 가장 많은데 방문 1회당 소비는 **1,975원**으로 가장 적습니다.

- 1차 사용자: 충북도·청주시 관광 담당, 청주공항 활성화 협의체, 충북문화재단(권역형 DMO), 심사위원

## 화면 흐름 — 담당자가 묻는 순서대로

| 순서 | 질문 | 화면 | 답(대만, 2026 상반기) |
|---|---|---|---|
| 0 | 결론은? | 첫 문장 | 입국은 2.1배로, 1인당 소비는 그대로. |
| 1 | 다른 공항과 비교하면? | 출발 안내판(공항 4곳, IATA 코드) | 청주 36,790원 · 김해 440,089원(12배) |
| 2 | 어디서 새나? | 충북 시군구 지도 | 방문은 청원구(공항)에 몰리고, 지갑은 흥덕구에서 열립니다 |
| 3 | 무엇이 끌어내렸나? | 요인분해 막대 | 일본 입국자의 1인당 소비 감소(−10,440원) |
| 4 | 그래서 얼마인가? | 노란 방향 표지판(체류 슬라이더) | 반나절 더 머물면 +2.0억 ~ 11.2억 원 |
| 5 | 믿어도 되나? | 접힌 「근거와 검증」 | 월별 추이 · 산식 · 검증 6종 · 한계 · 출처 · CSV |

각 섹션의 문장은 `src/lib/story.ts`가 데이터에서 만듭니다. 국적을 바꾸거나 데이터를 갱신해도 문장이 값과 맞게 바뀝니다(일본: "1인당 소비는 19% 줄었다.").
- 기능명세: `공항_체류전환_모니터_기능명세서.xlsx` v1.0 (기능ID·UI_id·규칙ID를 코드 주석과 `data-ui` 속성에 그대로 씁니다)

### V-World 배경지도(UI-05, 선택)

`.env.local`에 국토교통부 브이월드 인증키를 넣으면 지도 배경에 「지도」(WMTS `white`, 어두운 화면에서는 `midnight`)와 「위성」(`Satellite`)을 쓸 수 있습니다. Vercel에서는 프로젝트 환경변수 `VITE_VWORLD_KEY`로 넣고, 브이월드에 배포 도메인을 서비스 URL로 등록합니다.

```
VITE_VWORLD_KEY=발급받은-키
```

- 키가 없거나 타일을 못 받으면 「배경 없음」으로 되돌리고 안내합니다(ST-08). 기본값도 「배경 없음」입니다(단계구분도 가독성).
- **V-World 타일만** 요청합니다. 구글·네이버·카카오 타일은 쓰지 않습니다. 최대 줌 12, 공항 시설 확대·주석 표시 없음(BR-U3 — 청주·대구·김해는 군 공용 공항).
- 키는 코드에 적지 않습니다.

## 월 1회 갱신 절차 (OPS-01)

1. 데이터랩 **공식 화면·다운로드**로 받은 CSV를 `data/raw/`에 교체합니다(자동 수집 코드 금지, BR-C1). 파일명이 바뀌면 `data/config/sources.json`을 고칩니다.
2. `data/config/sources.json`의 `datalab_extract`(화면 표기)와 `card_extracted_on`(카드 추출일)을 고칩니다. 추출일이 2026-08-11 재소급 이전이면 경고가 뜹니다(BR-D3).
3. 두 명령으로 끝납니다.

```bash
npm run build:data     # 산출 + 검증 리포트 출력(FAIL이면 종료 코드 1)
git commit -am "데이터 2026.MM 갱신" && git push   # CI 통과 후 Vercel 배포
```

- 비교 반기를 옮길 때는 `data/config/settings.json`의 `halves`·`sgg.period`를 바꾸고 `tests/expected.json`을 새 기대값으로 교체합니다.
- 검증 관문: `npm run build`가 먼저 `scripts/check_report.mjs`를 돌려, 산출 JSON이 없거나 리포트에 FAIL이 있으면 **빌드(=배포)를 멈춥니다**. 시도-시군구 불일치 같은 경고는 빌드를 멈추지 않고 화면에 배지로 보입니다(DAT-06, ST-09).
- CI(`.github/workflows/ci.yml`)는 원천에서 다시 산출해 커밋된 JSON과 같은지(`npm run check:data`), 테스트, 빌드를 확인합니다.

## 구조

```
data/raw/        원천 CSV·경계(사용자가 교체). 받은 바이트 그대로 보관
data/config/     airports.json(공항-권역 쌍) · region_map.json(지역·국가명·코드 대응) · gu_cities.json(구 설치 시 보정)
                 settings.json(임계값·비교 반기) · sources.json(파일·추출일) · reference_values.json(공사 발표·원자료 결과값)
scripts/         indicators.py(산식, 표준 라이브러리) · build_data.py(적재·경계 변환·리포트·JSON) · check_report.mjs(배포 관문)
tests/           test_indicators.py · expected.json(기대값)
public/data/     indicators.json · sgg.json · boundary_43.geojson(WGS84) · meta.json(기준 시점·검증 리포트)
src/             React 화면(Vite + TypeScript, 지도 react-leaflet, 차트 SVG 직접 구현)
reference/       시제품 airport_monitor.html · compute_indicators.py(정답 구현) · 재현 안내
```

공항을 늘리려면 `airports.json`에 한 줄을 넣고 `npm run build:data` 하면 카드·차트에 자동으로 붙습니다(UI-12). 해당 권역 데이터랩 자료가 없으면 「자료 없음」, V2 검정을 통과하기 전에는 「참고값」으로만 보입니다.

## 데이터 원칙

- 모든 지표는 한국관광 데이터랩 공식 화면·다운로드 자료로만 산출합니다(크롤링·비공식 API 호출 금지).
- 방문자 수는 일자별 순방문자 기준 연인원 추정치라 시간·공간으로 합산하지 않고 월평균 비율만 씁니다. 카드 금액만 반기 합산합니다.
- 외래관광객조사 원자료는 개인 신청 자료라 커밋하지 않고 결과값(상관 0.92, 순위 0.93)만 씁니다(IS-05).
- 산출 기준: 입국 2026.07까지 · 데이터랩 2026.08 추출. 데이터 갱신 시 값이 달라집니다.

## 결정·미결 사항

- **요인분해 표기**: 참고 구현(`%d`)과 같이 원 미만을 버립니다(74,701.7 → 74,701). 국적별 1인당(r₀·r₁)은 카드 ①과 같은 값이라 반올림합니다(36,316).
- **시군구 월평균 방문**: 시군구 정리표와 같게 0.5는 짝수 쪽으로 반올림합니다(흥덕 일본 7,248.5 → 7,248).
- **인·일당 소비(① ÷ ②)**: 화면에 보이는 ①(정수)·②(소수 2자리)로 나눕니다(14,427원 · 81,048원 — 기능명세 AC 값).
- **DAT-06 부산·대구·제주 시도 = 시군구 합**: 현재 원천에 세 시도의 시군구 카드 CSV가 없어 「생략」으로 표시합니다. 데이터랩에서 해당 시군구 CSV를 받아 넣으면 자동으로 대조합니다. 충북은 「시도 카드 59.4억 = 청주 외 10개 시군구 합」으로 구 설치 시 제외를 확인합니다.
- **시군구 10곳(보은·옥천 등)**: 원천 CSV에 행이 없어 `충북_시군구_외국인_2026H1.csv`(데이터랩 화면 시군구 값 정리표) 값을 씁니다. 원천 행이 있는 7곳은 정리표와 14/14 일치를 리포트에서 확인합니다.
- 미결: IS-02(보정 대상 시 추가), IS-03(소표본 임계 300 근거), IS-04(V2 임계 민감도 — 표는 화면 PNL-02에 있음), IS-06(간편결제 단위), IS-08(배포 주소), IS-09(첫 숙박률 ③).
